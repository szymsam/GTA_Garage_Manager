# TheRealDriver46 — GTA Garage Manager v0.7

Wersja do GitHub Pages. Prześlij pliki i folder `assets` do katalogu głównego repozytorium, zachowując ich nazwy. Plik `index.html` musi znajdować się w katalogu głównym.

## Zmiany
1. Logo GTA Online z przesłanego pliku, nagłówek TheRealDriver46 bez podtytułu.
2. Liczniki na pasku nawigacji, większe, rozdzielone liniami, z odstępem od ustawień.
3. Lista garaży bez kategorii, w kompaktowym panelu.
4. Pionowe duże karty samochodów i kompaktowy pasek garażu: zdjęcie, nazwa, zajęte/pojemność, notatki.

Dane IndexedDB pozostają w tej samej bazie `gta-garage-manager` (wersja schematu 1). Przed aktualizacją wykonaj eksport kopii zapasowej. Nie usuwaj danych witryny.

Uwaga: logo w nagłówku jest znakiem GTA Online; wykorzystuj je zgodnie z prawami właściciela marki. Ikona PWA pozostaje ikoną garażu.
