# GTA Garage Manager v0.6

Wersja do GitHub Pages. Zachowuje dane kolekcji z v0.5 (IndexedDB), gdy adres strony pozostaje ten sam.

## Aktualizacja
1. W starej aplikacji wykonaj **Eksportuj kolekcję** i zachowaj kopię JSON.
2. Rozpakuj ZIP i prześlij **zawartość archiwum** do katalogu głównego repozytorium GitHub (nie dodatkowy folder).
3. Nadpisz istniejące pliki, zatwierdź Commit changes i poczekaj na publikację GitHub Pages.
4. Zamknij i otwórz ponownie aplikację PWA; jeżeli widać stare ikony, odśwież stronę. Nie czyść danych witryny / IndexedDB.

Zmiany: przesłana przez użytkownika ikona garażu jako logo i ikony PWA; konturowe, jednobarwne symbole samochodu, motocykla, garażu i nawigacji; odświeżony cache service workera. Zdjęcia pojazdów i garaży pozostają lokalne.
